## Featured Projects

**EEG Attention State Prediction**
Meta-learning pipeline with Bayesian uncertainty estimation for behavioral state
classification from EEG signals. Built with PyTorch using prototypical networks.

**SQL Data Warehouse**
End-to-end medallion architecture (bronze → silver → gold) in SQL Server with
automated ETL, data quality checks, and business-ready reporting layers.

**Electricity Consumption Forecasting**
Multi-model comparison (baseline → Random Forest → LSTM) for residential
electricity demand forecasting, evaluated with RMSE, MAE, and MAPE.
